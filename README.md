# Dossierassistent — openbare proefversie

Deze repository bevat uitsluitend gebouwde websitebestanden. Geen login. Gebruik alleen vooraf geanonimiseerde aantekeningen. De lokale AI deelt bestaande tekst in; hij schrijft geen nieuwe medische dossierinhoud. Actuele KNGF-/NHG-richtlijnen zijn nog niet geïntegreerd.

De modeldownload is circa 118 MB. De verwerking gebeurt op de eigen computer. De app bewaart geen casusinhoud; sluiten of vernieuwen verliest je werk. De klinische juistheid en werking op jullie werkplekken moeten nog worden beoordeeld.
